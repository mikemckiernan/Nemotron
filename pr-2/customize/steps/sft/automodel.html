SFT Training (AutoModel)#

SFT Training (AutoModel)

Supervised fine-tuning with the AutoModel stack for HF-format models and JSONL datasets that already use OpenAI chat-format messages. Supports full SFT and LoRA-style adapter tuning from the same step.

Category:

sft

Strategies

  • When: 1-2 GPUs or memory is tight; Then: prefer peft=lora and start with a Mistral-class model

  • When: 3-4 GPUs and the model fits comfortably; Then: consider full fine-tuning only if checkpoint size and iteration speed are acceptable; Skill: Automodel/docs/guides/llm/finetune.md

  • When: dataset already uses OpenAI chat-format JSONL; Then: skip data_prep/sft_packing and train directly from training_jsonl; Skill: Automodel/docs/guides/dataset-overview.md

  • When: you need an immediately deployable HF checkpoint; Then: save safetensors checkpoints and prefer the consolidated HF output layout; Skill: Automodel/docs/guides/checkpointing.md

Errors

  • Name: chat_template_missing; Recovery: use a tokenizer with chat-template support, or convert the data to prompt/completion format before training

  • Name: oom; Recovery: switch to peft=lora, reduce batch size, or move to a smaller model

"""SFT via NeMo-AutoModel. The recipe class is YAML-overridable.

By default uses ``TrainFinetuneRecipeForNextTokenPrediction``; set the
top-level ``_step_recipe`` key in YAML to swap in a different AutoModel
recipe class (e.g. classification, vision-language).
"""

from __future__ import annotations

from pathlib import Path

from nemotron.steps._runners.automodel import run_automodel

DEFAULT_CONFIG = Path(__file__).parent / "config" / "default.yaml"
DEFAULT_TARGET = "nemo_automodel.recipes.llm.train_ft:TrainFinetuneRecipeForNextTokenPrediction"


def main() -> None:
    run_automodel(default_target=DEFAULT_TARGET, default_config=DEFAULT_CONFIG)


if __name__ == "__main__":
    main()
